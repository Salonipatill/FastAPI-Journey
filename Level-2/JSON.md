JSON (JavaScript Object Notation) is a text-based data format used to store and exchange data between systems, especially between a frontend and backend/API.

```
JSON is mainly used to send and receive data between the client and server.
```

JSON is a lightweight data format used to exchange data between a client and a FastAPI server, mainly through request bodies and responses.

JSON supports:

String → "Saloni"
Number → 21
Boolean → true / false
Array → [1, 2, 3]
Object → {"name": "Saloni"}
null → null
