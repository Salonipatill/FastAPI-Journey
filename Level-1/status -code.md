HTTP status codes are 3-digit numbers sent by the server in the response to tell the client what happened to the request.

| Code range | Meaning       | Example                     |
| ---------- | ------------- | --------------------------- |
| **1xx**    | Informational | `100`                       |
| **2xx**    | Success       | `200 OK`                    |
| **3xx**    | Redirection   | `301`                       |
| **4xx**    | Client error  | `404 Not Found`             |
| **5xx**    | Server error  | `500 Internal Server Error` |
